# CaseResult 页面（单用例结果）

## 职责
单用例结果（v3.0 第 2.3 步）：输入输出 + 标准/额外指标分 + 简短评价。

## 路由
`/runs/:runId/cases/:caseId`

## 消费接口
| 函数 | 接口 | 说明 |
|------|------|------|
| `runs.cases` | GET `/runs/{runId}/cases` | 从用例列表找目标 case（或后端加单 case 接口） |

> 注：当前接口是列表分页，单 case 需前端从列表找或后端补 `GET /runs/{id}/cases/{caseId}`。

## 布局
- **用例信息**：用例编号/测试输入/预期结果/维度
- **执行结果**：被测 Agent 输出（agent_output，可折叠）
- **标准指标分**：表格（指标名/权重/分数/阈值/通过/理由）
- **额外指标分**：表格（指标名/分数/通过/理由，单独呈现不进主分）
- **主分**：overallScore + 通过判定（>= 4）
- **简短评价**：brief_comment（一句话）

## 状态
- 页面加载拉一次（从 runs.cases 列表找，或后端单 case 接口）

## 组件
- 用例信息卡片
- 指标分表格（标准/额外分开）
- 主分徽章（通过绿/失败红）
- 简短评价文本

## 权限
- 读：所有登录用户
