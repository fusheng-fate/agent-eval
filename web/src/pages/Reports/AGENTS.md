# Reports 页面（报告中心）

## 职责
报告中心（v3.0 第 5 步）：列表 + 详情（总览：KPI + 标准指标均分 + 额外指标均分 + **维度汇总**；用例透视：标准/额外指标分 + 简短评价）。删五层归因/裁判均分/诊断总结。加"导出 HTML"按钮。

## 路由
`/reports`（列表）
`/reports/:id`（详情）

## 消费接口
| 函数 | 接口 | 说明 |
|------|------|------|
| `reports.list` | GET `/reports` | 列表（keyword 筛选） |
| `reports.get` | GET `/reports/{id}` | 详情 |
| `reports.exportHtml` | GET `/reports/{id}/export.html` | 导出 HTML |

## 布局
### 列表页
- 报告表格（任务名/主分/用例数/通过/失败/创建时间/操作）
- 搜索（任务名）
- 操作：查看详情 / 导出 HTML

### 详情页
- **总览**：
  - KPI 卡片（主分/总用例/通过/失败/token/平均延迟）
  - 标准指标均分（表格：指标名/权重/均分）
  - 额外指标均分（表格：指标名/均分，单独呈现）
  - **维度汇总**（P24：表格：一级维度/二级维度/用例数/通过/失败/均分）
- **用例透视**：
  - 表格（用例编号/状态/主分/标准指标分/额外指标分/简短评价）
  - 点击行展开明细

## 权限
- 列表/详情/导出：所有登录用户（报告全局可见）

## 关键交互
- 维度汇总：按 dimension_l1/l2 分组，无维度的 case 归到 "-"
- 导出 HTML：`apiDownload`（blob 下载，自包含 HTML）
- 标准/额外指标均分分开呈现（额外不进主分）

- 报告是 run 完成后自动生成的（代码聚合，非 LLM）。
- 维度汇总依赖数据集的 dimension_l1/l2（可选列），无维度时该区块隐藏。
- 导出 HTML 是自包含的（内联 CSS），可直接发文件。
